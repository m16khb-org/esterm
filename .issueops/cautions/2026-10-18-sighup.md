# SIGHUP 과 강제 종료 때 자식 프로세스가 남을 수 있다

- Date: 2026-10-18
- Kind: `caution`
- Source: cli
- Summary: 터미널을 닫거나 esterm 이 강제 종료되면 ffmpeg/yt-dlp 가 고아로 남을 수 있었다.
- Context: SIGHUP 을 처리하지 않아 터미널 복구와 자식 정리가 건너뛰어졌다. 자식은 별도 프로세스 그룹이라 부모가 SIGKILL 로 죽으면 입력이 멈춘 ffmpeg 나 해석 중인 yt-dlp 가 ppid 1 로 남았다.
- Resolution: relay 와 minimap -json 이 SIGHUP 을 SIGTERM 과 같이 처리한다. 강제 종료(SIGKILL, 비정상 종료)에 대비해 모든 자식(yt-dlp, ffmpeg)을 파이프 감시자를 거쳐 실행한다(minimap_video.go `mmStart`): esterm 이 쓰기 끝을 쥔 파이프를 fd 3 으로 넘기고, 자식 그룹 안의 감시자(`( read _ ; kill -KILL 0 ) <&3 &`)가 EOF 를 받으면 그룹 전체를 죽인다. macOS 에는 부모 사망 신호가 없어서 쓰는 방법이다. 실측: SIGKILL 뒤 1.2초 안에 자식이 모두 사라졌다(느린 yt-dlp 흉내, 멈춘 입력 ffmpeg, 파일 ffmpeg). 회귀 테스트: TestMmStartParentDeath. 보조로 ffmpeg -rw_timeout 15s, yt-dlp --socket-timeout 15 도 둔다.
