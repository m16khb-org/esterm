# 라이브 헤더가 getLive 의 팀 순서를 그대로 써서 진영이 바뀐 세트에서 팀 이름과 킬·골드가 엇갈렸다

- Date: 2026-11-07
- Kind: `caution`
- Source: cli
- Summary: 킬·골드 막대와 선수 표는 피드의 blueTeam/redTeam 순서(블루 왼쪽)로 그리는데, 라이브 헤더의 팀 이름은 getLive 의 match.teams 순서를 썼다. getLive 는 세트마다 진영이 바뀌어도 같은 순서라, 레드 진영 팀 이름 아래에 블루 진영의 킬·골드가 보였다. 리플레이는 replayEvent 가 블루를 먼저 놓아서 맞았다.
- Context: 2026 Worlds 8강 T1-KC 3·4세트: getLive 는 T1, KC 순서, 피드의 blueTeamMetadata.esportsTeamId 는 KC. 사용자가 '팀 전체 킬 수가 반대로 표시된다'고 보고했다.
- Resolution: buildCanvas 가 피드의 blueTeamMetadata.esportsTeamId 가 두 번째 팀이면 이름과 시리즈 점수를 바꿔 블루를 왼쪽에 놓는다. 4세트 라이브에서 'Karmine Co… [1] … [2] T1' 로 맞는 것을 확인했다. 회귀 테스트 TestLiveHeaderPutsTheBlueSideTeamLeft.
