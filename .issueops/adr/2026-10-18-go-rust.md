# Go 유지, Rust 전환 안 함

- Date: 2026-10-18
- Kind: `adr`
- Source: cli
- Summary: 미니맵 검출 커널을 Go로 유지한다.
- Context: NCC 템플릿 매칭 단일 스레드 속도를 Go와 Rust로 측정했고, 실시간 파이프라인에서는 영상 디코드가 지배적이었다.
- Decision: 구현 언어를 Go로 유지하고 goroutine 병렬로 전체 탐색을 약 20ms로 줄인다.
- Consequences: Rust 대비 단일 스레드 1.1~1.4배 느리지만 단일 바이너리와 표준 라이브러리 전용 정책이 유지된다. 근거: /tmp/nccbench(커널 측정), /tmp/decbench(디코드 측정, 일회용). Rust 재작성은 이득이 작아 재시도하지 않는다.
